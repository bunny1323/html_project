# Distraction-Free YouTube (HTML Mini Project)

A simple distraction-free YouTube experience built using HTML.  
This is my first mini project using **HTML** that provides clean, focused pages without recommended video clutter.

---

## 🎯 Project Overview

The main idea of this project is to provide minimal YouTube-like pages for different use cases (study, music, gaming) without distractions like comments, recommended videos, or sidebars — just clean content. 2

---

## 🛠️ Technologies Used

- **HTML** (100%) — no frameworks, just simple markup. 3
